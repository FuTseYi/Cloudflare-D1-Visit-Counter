# Changelog

Notable changes to Cloudflare D1 Visit Counter are recorded here. For full release details, follow each version link.

## [v2.0.0](https://github.com/FuTseYi/Cloudflare-D1-Visit-Counter/releases/tag/v2.0.0) — 2026-10-18

- **Added:** Private `/admin` dashboard, bilingual EN/中文 UI, redesigned public showcase, and modern analytics report.
- **Added:** Authenticated counter URL/key renaming with atomic D1 migration, historical aliases, search/sort, and secure owner navigation.
- **Improved:** Mobile layouts, badge previews, embed snippets, accessibility and automated tests.
- **Fixed:** Cloudflare Error 1101 on status and monthly statistics routes.
- **Compatibility:** No database schema migration; existing stored visits and counter endpoints remain usable.

See [v2.0.0 release notes](docs/releases/v2.0.0.md).
